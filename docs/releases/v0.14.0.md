# v0.14.0

> 工作区级 Web 小说创作工作台与公共表面收口版本。v0.14.0 把原创、单作品同人和跨作品同人的创建、项目驾驶舱、章节工作台和受控 Codex 任务纳入同一个本地 Studio，同时移除已被当前协议替代的旧代码和公开验证、对比表面。

## 主要变化

- 新增工作区级 Workspace Studio，可在浏览器中创建原创、同人和跨作品同人项目，并从当前唯一安全动作继续生产。
- `studio serve --workspace WORKSPACE` 管理明确绝对工作区；项目和 `--chapter N` 可直接打开对应驾驶舱或章节中心。
- 新增 `studio shortcut-install --workspace WORKSPACE`，为 Windows 安装固定工作区的桌面入口；同一工作区的后续启动复用当前本机实例。
- Web 后端只能为当前 `AgentTaskManifest v5` 创建受控 Codex Job。输入复制到隔离 staging，唯一输出通过协议校验后才回到 workbench；浏览器不接受任意 Prompt、命令或输出路径。
- Studio 统一显示章节草稿、Story Brief、合同、审稿、人工修订、定稿、语义应用和关闭状态；独立 `review serve` 作为兼容与恢复入口保留。
- 删除旧 `longform_engine.reader_promises` 模块，运行时只使用 `reader_promises_v2`。
- 删除已无调用的旧 Agent、Source Protocol、生产状态、质量审查、编排投影和小型辅助实现，不提供旧名称转发或双读。
- 将当前架构与存储事实合并到无版本号主文档，删除阶段 Implementation、Release Checklist 和 Benchmark Runbook。
- README、Skill、Web 和公共命令协议不再展示测试成绩、文学盲评、Benchmark、RAG 规模结论或市场横向对比。

## 公共接口变化

- 公共 `longform-engine benchmark ...` 命令组不再注册；内部 Benchmark、Blind Review、RAG scale 和市场比较 Python 实现保留。
- `quality contract --compare-market` 不再是公共参数。
- `quality status` 返回 `quality_status_v3`，不再投影文学盲评或 Benchmark 证明字段。
- `longform_engine.reader_promises` 不再可导入；读者承诺调用方必须使用 `longform_engine.reader_promises_v2`。
- 旧项目配置、旧 Reader Promise 协议和已删除的资料候选协议不增加迁移、双读或兼容 shim。

## 发行形式

v0.14.0 以不可变 Git tag 直接发布源码。本次不创建 GitHub Release 页面，不提供 wheel、sdist 或 `SHA256SUMS`。安装时应明确固定 `v0.14.0` tag；如需制品，维护者可以日后针对该不可变 tag 手工启动 Release workflow。
