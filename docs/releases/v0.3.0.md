# longform-novel-engine v0.3.0

`v0.3.0` 是 `ylqit/novel-general` 的首个公开 GitHub 发行版，面向 Codex App、Codex CLI 与 Claude Code 的中文长篇小说生产。

## 主要内容

- 提供 pipx + Git tag 的 engine 安装方式，以及 `skills install/status/update/uninstall` 完整 Skill 生命周期。
- Codex 与 Claude Code Skill 自包含安装，不需要 OpenAI、Anthropic 或其他 provider API key。
- 统一使用 `production next -> agent-task brief -> Agent output -> validate -> explicit apply/finalize` 协议。
- 加入项目级创意、开书、纲要、研究、风格、同人 canon 与设计任务。
- 加入人物表达合同、章节人物包、场景化叙事约束、Humanizer v4 与风险驱动编辑审稿。
- 加入起点男频主合同及番茄免费阅读非阻断兼容提示。
- 加入 `chapter_semantic_bundle_v1`，一次抽取章节摘要、事件、关系、角色状态、伏笔与检索路由。
- 加入章节关闭和产物归档接口，减少长期生产中的松散重复文件。
- 保持 final、Bible、outline、semantic ledger、RAG、graph、TCS 与 SQLite 的显式写入边界和事务回滚。

## 安装

```text
python -m pipx install "longform-novel-engine[semantic] @ git+https://github.com/ylqit/novel-general.git@v0.3.0"
longform-engine skills install --tool all
longform-engine doctor --tool all
```

完整 PowerShell、Bash、升级、卸载和首次开书命令见 [README](https://github.com/ylqit/novel-general/blob/v0.3.0/README.md)。

## 兼容与边界

- Python 3.10、3.11、3.12。
- 旧版 AgentTaskManifest v1 和分立 graph/memory/character 任务保留兼容读取路径；新生产流程优先使用 v2 与统一章节语义包。
- 不自动 finalize，不绕过 book、outline、research、graph、memory 或 semantic apply 的人工边界。
- 本版本证明工程工作流与本地 Codex 五章 smoke 可运行；尚不宣称文学质量已全面优于 `novel-skill`，该结论仍需要同模型十章对照和独立盲评。
