# longform-novel-engine v0.4.1

`v0.4.1` is a breaking protocol, Prompt, Schema and context-engineering release for Chinese long-form novel production with Codex App, Codex CLI and Claude Code.

## Highlights

- Deepens 27 task-bound professional roles, 12 Chinese writing Playbooks and 44 composable story-facet adapters with independent decision models, diagnostics, repair boundaries and calibration fixtures.
- Uses progressive Prompt sections so each task loads only its role, current method modules and at most three active story facets.
- Adds adaptive context budgets and explicit project, chapter-author, isolated-revision, isolated-review and archival session policies.
- Reduces Agent output to four protocols: `prose_markdown_v1`, `design_document_v1`, `evidence_review_v1` and `canonical_delta_v1`.
- Introduces immutable AgentTaskManifest v4 and a Markdown-authoritative design workflow with evidence-bound semantic compilation before canonical apply.
- Keeps final manuscript, graph, memory, foreshadowing, TCS, RAG and SQLite behind explicit CLI validation and transactional apply/finalize boundaries.

## Scope And Limits

- `v0.4.1` does not support v0.3.x or v0.4.0 project protocols. Start a new project.
- The 27 roles, 12 Playbooks and 44 facets have structural and fixture validation, but independent literary blind review is not complete.
- The planned SAO ten-chapter quality run is post-release evidence and is not included in this release.
- This release does not claim literary quality is superior to `novel-skill`.
- No npm or pnpm package is published. The supported distribution is Python wheel/sdist plus bundled Codex and Claude Code Skills.
- The no-key Host Agent workflow remains unchanged: Agent output must pass CLI validation and explicit apply/finalize boundaries.
