# v0.15.0

> 小说工作台阅读、规划、修订与反馈流程增强版本。本次将 v0.14.0 后的工作台改动纳入新的不可变安装版本，使源码、发行资源与 Codex Skill 可以同步更新。

## 主要变化

- 多作品书架显示实际卷章、正文状态与最近修改；支持历史正文、资料、归档版本阅读及正文和资料搜索。
- 提供作品、卷、章节与选段讨论，保存备忘、意图草稿、完整候选和规划提案；来源变化后明确显示旧建议失效。
- 原创开书采用三步引导，同人增加来源步骤；支持填写进度恢复、自动项目标识、高级参数折叠和创建前复核。权利声明与最终确认不从浏览器草稿自动恢复。
- 规划页展示批准有效的全书主干、当前卷、近期章节、后续方向与展望，并对照候选中的合同、保护项、节点依赖和移除项。
- 修订页支持冻结原稿和修改稿的准确选段引用、重复句段消歧及 Unicode 位置绑定；候选变化后，旧意见与引用按原有规则失效。
- 技法采用绑定当前分析及原始来源，填写本作转化、适用条件、保护项与预期效果；只有本轮明确选择的有效提案进入规划作者和独立审稿工作单。
- 增加正式正文中的技法效果回查，以及读者反馈批次、人工决定、提案转换和规划交接；这些记录本身不修改 Canon。
- 质量观察、技法效果与独立文学评测分别展示；改进窄屏阅读、键盘焦点、空内容、读取失败重试与过期状态。

## 协议与安装

- 保留 Manifest v5、现有五类 Agent 输出协议、人工批准、独立审稿及 transaction v3；本次不引入小说数据迁移。
- 版本统一为 `0.15.0`，通过新版引擎的 Skill 安装器同步内容与安装元数据，不能只修改本地 Skill 版本标识。
- 本机更新范围为全局引擎、仓库开发环境和 Codex Skill；Claude Code Skill 不属于本次本机更新范围。
- 原有 `v0.14.0` Tag 保持不变。使用本轮功能需安装 `v0.15.0`，旧 Tag 不包含这些后续工作台改动。

## 发行形式与验证边界

本次由用户明确要求发布 Git 提交、不可变 `v0.15.0` Tag 和 GitHub Release，并跳过回归测试、smoke、CI、静态检查、readiness、制品审计及 doctor。仅进行版本与文档同步、Skill 引用同步、资源清单生成、打包、上传和本地安装。

Release workflow 从该 Tag 构建 wheel、sdist，并生成 `SHA256SUMS`。制品构建和安装命令成功不等于功能、兼容性或文学质量验证通过。本次不追加“测试通过”结论。

历史工程验证记录见 [工作台优化 Checklist](../WEB_STUDIO_OPTIMIZATION_CHECKLIST.md) 和 [Web 验收记录](../WEB_STUDIO_ACCEPTANCE.md)，其日期、版本与范围保持原记录，不能当作本次发行的重新验证。真实连续章节闭环、长期写作效果及独立人类文学验收仍保留原有未完成边界。
