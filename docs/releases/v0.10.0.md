# v0.10.0

v0.10.0 replaces the v0.9 production protocol. Existing v0.9 projects and evidence are intentionally incompatible; there is no migration, alias, or dual-read path.

## Highlights

- Makes `chapter_contract_v5` the only formal chapter contract.
- Adds Book Spine, volume skeletons, one active volume, a rolling 20-chapter window, three firm contracts, independent semantic review, and explicit human approval for every firm plot node.
- Upgrades the author chain to `human_chapter_intent_v2`, `chapter_story_brief_basis_v3`, `chapter_story_brief_v5`, `chapter_writing_task_v7`, and renderer v5.
- Requires human-confirmed event realization and exact final/semantic-ledger evidence for every non-defer reader-promise action before chapter close.
- Adds stable-ID canonical facts, deterministic dependency impact, future-artifact staleness, and `revision_branch_v2` routing for historical impact.
- Adds non-canonical human reader-feedback batches that can only produce planning or canon-change proposals.

## Platform boundary

Qidian remains the primary editorial profile and Fanqie remains a non-blocking observation profile. This release does not claim AI-detector evasion, platform acceptance, or a human-writing percentage. `literary_evidence_ready` remains `false`.
