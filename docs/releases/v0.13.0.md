# v0.13.0

> 国内平台同人长篇生产架构发布。v0.13.0 以 v0.12 的开放语义和可回滚事务为底座，正式加入路线家族、章节上下文 v2、跨界拓扑、目标平台配置和仅约束平台导出的人工权利决定。

## 主要变化

- 同人故事发动机新增 `oc_si_progression | canon_character_centered | hybrid` 三种 `route_family`，并强制声明主角与原著关系、读者识别承诺和脱离原著事件后仍可运转的原创主线。
- 原著事件命运扩展为“基线、初始变量、处置、职责承担者、一阶影响、二阶影响、新问题”，全部影响和卷章范围引用稳定批准声明。
- 每个获批重大分歧独立、幂等地创建未来知识重估；知识范围可更新为仍可靠、部分可靠、已失效或反向误导。
- `fanfiction_context_bundle_v1` 原子升级为 `fanfiction_context_bundle_v2`。v2 使用章节显式引用、带理由递归依赖、结构化来源分区、作者/审阅双投影、命名冲突和逐分区预算；旧包必须重新编译。
- 原著保真审阅只接收 v2 的精确 review projection 和 evidence 闭包，不再把完整 Canon、故事发动机和路线文档整体投入审阅。
- 跨界路线新增 `fixed_host | fusion_world | sequential_worlds` 拓扑，以及按 `character | body_or_soul | ability | item_or_contract | knowledge | organization | world_rule` 实际载荷派生的来源适配要求。
- 跨界验证采用“来源适配器 → 项目跨界宪法 → 当前卷例外”，不建立作品间 N×N 战力矩阵；顺序诸天要求跨卷保留关系、身体状态、债务、敌对关系、知识失效或总目标进度。
- 目标平台进入项目配置、内容提示和发布预检，但不预测平台接受。
- 平台政策注册表分开记录分类、投稿、签约、激励、内容治理、权利风险、披露要求和未知项。
- `platform_publication_preflight_v1` 升级为 v2，增加 `rights_decision_status`、`decision_stale` 和 `export_blocking`。
- 新增 `fanfiction_publication_rights_decision_v1` 和命令：

```text
longform-engine publication rights-decision project.yaml --target qidian_male|fanqie_free --decision proceed|hold --approved-by HUMAN --note NOTE
```

- `publication export` 现在必须提供 `--target`。同人项目只有在该目标的人工决定为当前 `proceed` 时才能导出；缺失、`hold`、配置/Canon/来源声明/政策 hash 漂移或政策过期只阻断对应平台导出。普通创作和原创项目不受该门禁影响。

## 兼容性

- 项目配置继续使用 schema v2，不新增作品专用字段。
- `fanfiction_context_bundle_v1`、`platform_publication_preflight_v1` 和含义不完整的旧 crossover 路线不双读；相关故事发动机、路线、上下文、审阅和发布决定必须按当前来源重新生成。
- `publication export` 缺少 `--target` 会直接失败；自动化脚本必须显式选择 `qidian_male` 或 `fanqie_free`。
- v0.12 的开放 `semantic_document_v1`、人工决定、stable claim、事务 v3、`chNNN.md` 正文命名和非原地 v0.11 导入边界保持不变。

## 发布边界

本版本不自动抓取原著全文，不自动登录或投稿平台，不声称取得原著授权、提供法律意见、预测签约/激励/审核结果、证明“非 AI”或规避检测。人工发布决定仅表示作者理解当前风险并承担流程责任。
