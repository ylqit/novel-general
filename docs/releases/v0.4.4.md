# longform-novel-engine v0.4.4

v0.4.4 closes the remaining canonical-write and product-language gaps in the v0.4 line.

## Changed

- Runs reviewed research promotion inside transaction v3 across canon, impact ledger, inbox state, RAG context/cache, graph, and SQLite.
- Runs revision rollback inside transaction v3 across detached manuscripts, stale/quality/memory/vector state, Agent task lifecycle, and SQLite.
- Requires an explicit `chapter_direction` for every unapplied chapter and uses `mandatory_chapter_direction` as the base reason.
- Renames readiness schema to `agent_data_pipeline_readiness_v4` and `production_chain_ready` to `production_contract_ready`.
- Aligns current Humanizer, RAG, graph, command, and Skill guidance with Humanizer v4 and unified semantic materialization.

## Breaking interface changes

- `RevisionRollbackResult.snapshot_dir` is removed; use `transaction_report`. Successful detached material remains under `40_manuscript/detached/`.
- `ResearchPromoteResult` now includes the project-relative `transaction_report`.
- Readiness JSON no longer emits `production_chain_ready`; consumers must read `production_contract_ready`.
- In-flight chapter-direction candidates carrying the retired `guided_mode` reason must be regenerated.

## Distribution

- Source version, packaged Skills, release channel, resource manifest, wheel, and sdist are versioned as `0.4.4`.
- `literary_evidence_ready` remains `false`; structural release gates are not literary-quality proof.
