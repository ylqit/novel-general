# longform-novel-engine v0.3.2

`v0.3.2` is a protocol and operational stability release for the no-key Codex/Claude Code workflow.

## Highlights

- Adds task-bound Prompt roles, compact Agent-first result adapters, reproducible prompt/context hashes and a guarded data-pipeline readiness boundary.
- Fixes the pacing review control-plane/domain-validator split. Pacing results now bind the current task, result path, SHA-256, diagnostic and lifecycle before semantic apply.
- Adds unified chapter semantic materialization, transaction cleanup, Windows-safe snapshot paths, SQLite rollback participation, shared user-level model caches and stricter artifact diagnostics.
- Adds v3 content-addressed chapter audit packages, compact task/event projections and benchmark verification that can read archived evidence.
- Makes bundled-resource and Skill tree hashes reproducible across operating systems, and audits every wheel resource against the manifest instead of checking presence alone.
- Completes a real five-chapter Codex SAO engineering smoke: five finals, semantic ledgers and closures; three archived chapters; zero unresolved P0/P1 and zero canonical pollution; chapter 6 is the next action.
- Verifies real shared-cache `bge-m3` indexing and retrieval without fallback. CPU cold-start retrieval remains expensive and is not presented as a performance result.

## Scope And Limits

- The five-chapter run contains resolved protocol incidents and is reported as an engineering smoke, not as an incident-free run.
- The 20-chapter production run and human literary acceptance are deferred.
- This release does not claim literary quality is superior to `novel-skill`.
- Project data created by `v0.3.0` or `v0.3.1` is not guaranteed to be compatible. Start a new project for production validation.
- This release does not add script-internal LLM providers or API-key requirements. Agent output still passes CLI validation and explicit apply/finalize boundaries.

## Install

```text
python -m pipx install --force "longform-novel-engine[semantic] @ git+https://github.com/ylqit/novel-general.git@v0.3.2"
longform-engine skills install --tool all
longform-engine doctor --tool all
```
