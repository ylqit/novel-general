# longform-novel-engine v0.4.2

`v0.4.2` is a repair-coordination and review-lifecycle release for Chinese long-form novel production with Codex App, Codex CLI and Claude Code.

## Highlights

- Adds the 28th task-bound role, `repair_coordinator`, without adding another Agent output protocol.
- Requires deterministic checks, semantic continuity, reader payoff, pacing and selected editorial reviews to finish against the same immutable candidate hash before repair synthesis.
- Freezes a compact review bundle with stable finding IDs, evidence, repair targets and preservation requirements.
- Preserves evidence-backed minority P0/P1 findings; the repair coordinator cannot delete, outvote or downgrade them.
- Uses immutable `r01` and `r02` repair plans, manifests, candidate snapshots and replacement drafts.
- Consumes a repair attempt only after a complete replacement candidate is submitted; after two failed rounds the workflow stops at `repair_budget_exhausted`.
- Removes the duplicate gate-level `repair_plan.md` source and keeps repair planning in the workbench.
- Normalizes review lifecycle control so content findings do not prevent the remaining independent reviews from running.
- Uses raw file-byte SHA-256 bindings consistently across gate and reader-payoff review on Windows and Unix-like systems.
- Keeps the active project-readiness task ahead of chapter work in `production next`, and sends `awaiting_agent` tasks through `agent-task brief` before validation.

## Validation

- Full single-process test suite: 296 passed.
- Codex and Claude Code Skill reference synchronization and validation passed.
- Agent-first data-pipeline readiness passed with 28 roles, 25 task types and four Agent output protocols.
- Resource manifest, release surface guards, wheel audit and sdist audit are release gates.

## Scope And Limits

- `v0.4.2` does not promise compatibility with v0.4.0 or earlier project protocols. Start a new project.
- Existing v0.4.1 failed-production evidence remains historical and is not rewritten by this release.
- Independent mixed-genre literary blind review is still incomplete.
- Literary quality evidence remained incomplete in this release.
- No npm or pnpm package is published. Distribution remains Python wheel/sdist plus bundled Codex and Claude Code Skills.
- No script-side LLM provider or hidden API-key requirement is introduced.
