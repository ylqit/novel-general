# longform-novel-engine v0.4.0

`v0.4.0` is a breaking project-protocol release for length-driven, mixed-profile Chinese long-form novel production with Codex App, Codex CLI and Claude Code.

## Highlights

- Makes `target_total_characters` the primary scale contract and uses one `content_characters_v1` metric across planning, gates and completion checks.
- Replaces fixed full-book chapter enumeration with rolling outline windows, dynamic chapter forecasts and human-approved story-arc extension.
- Adds composable story facets for market, setting, plot engines, narrative forms, premise devices, relationship modes, tone and creation mode.
- Activates at most three relevant facets per chapter and requires an explicit `chapter_direction_candidate_v2` decision before writing.
- Strengthens character and scene review around visible goals, motivated choices, named supporting characters, distinguishable dialogue and evidence-backed findings.
- Validates the 2,000,000-character engineering scale with bounded rolling context, task projections and the `local_hnsw` semantic backend.

## Scope And Limits

- `v0.4.0` does not read v0.3.x project configuration or outline schemas. Start a new project.
- The 2,000,000-character result is synthetic engineering evidence, not proof of literary quality.
- Two mixed-profile five-chapter blind reviews remain post-release quality evidence.
- This release does not claim literary quality is superior to `novel-skill`.
- The no-key Host Agent workflow remains unchanged: Agent output must pass CLI validation and explicit apply/finalize boundaries.
- No npm or pnpm package is published; the supported distribution is Python wheel/sdist plus bundled Codex and Claude Code Skills.

## Install

```text
python -m pipx install --force "longform-novel-engine[semantic] @ git+https://github.com/ylqit/novel-general.git@v0.4.0"
longform-engine skills install --tool all
longform-engine doctor --tool all
```
