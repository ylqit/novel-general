# v0.12.0

> 破坏性语义优先发布。完整的本地验证、远程 CI、不可变 tag 和 Release 制品记录见当前发布 Checklist。

v0.12.0 将未发布的 v0.12–v0.14 多媒体实验合并为一次语义优先重构，不再发布依次依赖的空壳 v0.13/v0.14。它保留格式探测、文档解析、OCR、字幕、ASR、视频轨道/关键帧、证据定位和 Studio 安全代码，同时把人物、事件、关系、能力、外观和跨作品规则从封闭字段迁移到“最小硬壳 + 中文语义文档”。

主要变化：

- 新增 `artifact_envelope_v1`、`evidence_reference_v1`、`workflow_record_v1`、`semantic_document_v1` 与 `human_decision_v1`，并启用 `agent_task_manifest_v5`。
- Host Agent 负责搜索规划、资料理解、事实归纳、人物理解、路线/故事设计、章节语义规划和分目标审查；Python 负责身份、哈希、权限、证据、状态、事务、版本与回溯。
- 原著证据、项目原著基线、同人连续性与小说故事 Canon 分层；正式主张必须经过独立复核和人工批准。
- 覆盖改为当前创作需求驱动，`design_core` 与当前 `chapter_dependency` 是默认硬门禁，全作截至截止点覆盖改为人工可选。
- 中文长篇同人链增加人工批准的故事发动机、四种时间/知识范围、原著事件命运、原著人物职责、动态跨界宪法和隔离路线复核；同人基线获批不再直接解锁路线。
- 新增可重建的 `fanfiction_context_bundle_v1`：以稳定 claim 引用、依赖闭包和 Token 预算编译章节上下文，移除姓名匹配、固定条数和“无命中取前几条”正式回退；`chapter_story_brief_basis_v3` 绑定其 hash。
- `canon_fidelity_reviewer` 分开审查原著一致性与同人创造性；起点主画像条件叠加 `cn_longform_fanfiction`，番茄继续保持 P2 非阻断观察。
- 活动检索域收口为 `source_evidence/project_canon/project_story`。不建设同人作品样本库；用户提供的案例和技法只提炼到仓库 Prompt、质量规则、抽象验收夹具、文档与 Skill。
- 新增非 Canon 创作沙盒、最近三章 firm 的滚动规划、重大节点审批、可读 Story Brief、人物分时期理解和跨作品自然语言兼容规则。
- Studio 使用统一中文语义编辑器与状态驱动页面，不自动批准 Canon、联网、提升沙盒或修改 final。
- 提供 v0.11 只读审计与非原地单向导入；旧事实进入待审重建候选，旧图谱/RAG/SQLite 失效，已定稿正文不自动改写。

兼容性：`fanfiction_source_canon_v1/v2/v3` 及旧固定内容协议不再双读。内部资料索引和媒体规范化记录仍可使用确定性结构，但它们不是人物/剧情语义本体，也不能直接成为项目 Canon。

本版本提高的是证据可回溯、语义协作和长篇生产质量，不实现 AI 检测规避，不承诺起点、番茄或其他平台接受，也不保证同人角色行为百分之百符合原著。
