# 人物塑造与自主性

## core
人物差异至少来自五层：优先注意什么，如何解释事实，遇压时先做什么，用什么理由说服自己，面对不同关系对象如何改变表达。配角必须有稳定姓名或 ID、当下私欲、不能让步的边界和独立反应；其行动不应只为递送信息、赞美主角或制造方便。

## creation
人物特征通过选择、失误、身体习惯、资源使用和关系后果呈现，不用标签、外貌清单或固定口头禅替代。人物变化必须有触发、抵抗和代价；即使最终接受建议，也应保留自己的判断过程和利益位置。

## review
逐人检查注意对象、利益、选择、拒绝能力和关系后果，再做“移除姓名”和“互换行动”测试。核心人物整章没有选择且章节职责依赖其推动时属于严重失效；局部声音相近但行动逻辑不同通常只是表达问题。配角只递送信息、赞美或服从时，需用连续证据证明工具化。

**诊断分支**
- 欲望不可见：从角色愿意冒什么风险、拒绝什么便利反推本场目标，不用性格标签代替。
- 选择被代做：把提问、判断或最后决定还给应承担后果的人，主角不能垄断全队能动性。
- 关系无后果：检查选择是否改变信任、债务、边界或职责，只有情绪评价不算关系移动。

## repair
先找出被剥夺的决策点，为角色恢复一个与主角不完全一致的欲望、边界和可执行动作，再让该动作改变成本或关系。保护既有能力、知识和剧情结果，不靠新增身世、口癖或性格标签制造差异。

**保护项**：保护人物既有价值排序、关系阶段和能力边界；不能为了显得主动而让角色无依据鲁莽。

## facets
成长文重点看能力增加后责任和选择是否变化，群像看非主角能否改写计划，言情看双方是否都有拒绝权，同人看原作角色是否保留价值排序，穿越文看先验知识是否替代了人格。弱势或受控角色也能通过隐瞒、拖延、谈条件和承担代价表现自主性。

## examples
1. 正例：配角同意合作却扣下通行证保障家人；反例：听完主角分析便无条件交出全部资源。
2. 正例：主角因害怕失控选择隐瞒，随后承担盟友撤离的后果；反例：旁白说他多疑，但每次都立刻相信陌生人。
3. 正例：弱势角色不能拒绝命令，却通过延迟执行保护自己的底线；反例：弱势角色只负责说“你说得对”。

## false_positives
人物在强约束下服从不等于没有自主性，只要正文显示其判断、边界或代价。

## calibration
边界例：受伤角色本章无法行动，不等于工具化；需看其判断是否影响他人。角色接受合理建议不等于失去自主性；关键在于正文是否呈现其利益位置、选择过程与承担的后果。
