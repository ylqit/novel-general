# 连载节奏与读者收益

## core
节奏取决于章节职责，不等同于全程快速。压力、释放、发现、关系、成长、失败和余波应形成变化；连续多章承担同一职责会产生疲劳。慢章仍须改变人物状态、关系、计划或读者认知，快章也必须保留必要的空间、因果和情绪落点。

## creation
每章明确读者实际获得什么、人物付出什么、哪项承诺推进或改写。结尾可以收束、决定、发现、关系变化或新问题，不强制悬崖。卷级高潮兑现此前积累的承诺，并让新问题由既有因果产生。

## review
绘制各场景的压力、释放、转折和余波曲线，并记录读者获得、人物代价与承诺变化。核心转折没有准备或余波导致因果断裂时可升级；局部节拍相似通常只是疲劳风险。慢章按状态变化判断，快章按空间与因果可读性判断，不使用句长或对白比例配额。

**诊断分支**
- 职责重复：比较压力来源、承担者、收益和后续条件，合并真正同功能的 beat。
- 关键跳步：补决定胜负、关系或认知转折的最小选择过程，不扩写所有过渡。
- 余波缺失：补状态确认、代价分配或关系反应，而不是立刻追加更大敌人。

## repair
先辨认问题是重复、跳步还是余波缺失：重复则合并同功能 beat，跳步则补关键选择，余波缺失则增加状态确认。保护本章应有的快慢属性和已成立场景，不用突然加敌人或强制悬崖制造速度感。

**保护项**：保护章节应有的快慢属性、已有高潮和必要恢复，不用平台配额覆盖故事因果。

## facets
成长文轮换获得、试用、代价和整合，悬疑轮换证据、误判、修正和揭示，言情轮换靠近、边界、误读和修复，群像通过能动性轮换形成节奏。同人熟悉事件不能直接快进，仍需为本书的新分歧与人物选择留下场景。

## examples
1. 正例：战后慢章通过伤员分配改变队伍权力；反例：连续三章复述担忧却没有新选择。
2. 正例：追逐章压缩解释，但在失败后留出一次代价确认；反例：连续转折没有空间和情绪落点。
3. 正例：卷末兑现旧承诺后由既有代价产生新问题；反例：每章结尾都突然出现更大敌人。

## false_positives
安静、恢复和余波章节并非停滞，只要人物状态、关系或读者认知发生变化。

## calibration
边界例：连续两个慢章可以分别承担关系决定与计划重构，不算职责重复；短章也可能拖沓，若所有段落功能相同。平台追读偏好是 advisory，不能覆盖本章因果与人物余波。
