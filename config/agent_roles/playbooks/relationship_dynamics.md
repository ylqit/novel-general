# 关系推进

## core
关系不是好感数值，而是双方目标、信任、权力、债务、秘密和边界的组合。每次重要互动至少改变其中一项，或明确显示为什么暂时不能改变。误会必须来自信息不对称、性格防御或利益冲突，不能依靠所有人拒绝说一句正常的话。

## creation
爱情、友情、家庭、师徒、团队和宿敌线都要求双方拥有主线之外的个人目标。亲密感通过共同经历、准确理解、承担代价和边界协商建立；冲突解决后要有行为余波，不能一句道歉恢复原状。

## review
比较互动前后的信任、权力、债务、秘密、边界和可拒绝空间。核心关系突变却没有触发、抵抗和余波时属于因果问题；一场互动没有升温并非失败，只要产生了明确抵抗或维持现状的代价。不能用对白里的关系宣言替代行为证据。

**诊断分支**
- 单方推进：检查另一方是否拥有目标、拒绝权和行动后果，不能把沉默当默认同意。
- 宣言无证据：将亲近、敌对或和解落到权限、秘密、债务和边界的实际改变。
- 误会机械延长：确认信息差、防御机制或现实利益足以阻止澄清，否则重构冲突来源。

## repair
冻结关系前置状态与本章结果，让双方各自提出条件、承担代价或守住边界，并在冲突后留下一个可追踪的行为余波。误会应补足信息差或防御机制，而不是强迫人物拒绝常识性沟通。

**保护项**：保护双方独立目标、既有伤害和关系阶段，不能用一次道歉清零长期后果。

## facets
言情优先检查双方边界与互惠，团队检查权限和风险分配，家庭检查旧模式如何介入当下，师徒检查依赖向独立移动，宿敌检查双方标准与可赢领域。同人关系线还需尊重 canon 阶段，AU 变化必须由分歧链支持。

## examples
1. 正例：道歉被接受，但受伤者仍收回共享权限；反例：一句道歉让长期背叛归零。
2. 正例：盟友提供情报却要求退出权，信任与边界同时变化；反例：一次救援后双方立刻无条件交心。
3. 正例：误会源于一方隐瞒保护对象，澄清后仍留下控制欲问题；反例：两人只要说一句常识就能解决却拖十章。

## false_positives
关系维持现状也可以成立，只要正文展示了阻碍变化的力量和人物选择。

## calibration
边界例：稳定关系章节可以通过共同习惯深化，而不必制造争吵；恋爱线中的吃醋只有暴露边界或欲望才有功能。权力不对等关系的“同意”要检查选择空间，不能只看口头接受。
