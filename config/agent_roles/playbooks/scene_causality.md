# 场景与因果

## core
有效场景包含具体目标、当下阻力、人物行动、局势变化和可感后果。进入场景时尽快给出人物正在做什么、为何现在做、环境如何妨碍；离开场景时必须有信息、关系、资源、危险或决定发生变化。动作、感官、对白和心理应共同作用于冲突，不能各写一段互不相干。

## creation
叙述压缩适合移动、重复劳动和不含关键选择的时间段；关键决定、关系转折、线索发现和能力代价必须落成可观察场面。不要把“他们争论很久”“他终于明白”当作场景本身。

## review
把章节划成场景，逐一核对进入条件、即时目标、阻力、关键选择、状态变化和离场后果。关键转折若只出现在概述句中且承担本章职责，属于核心场景缺失；若只是移动或重复尝试，压缩合理。证据不足以判断场景边界时先标 insufficient，不凭段落长度定性。

**诊断分支**
- 缺入口条件：补谁在何处因何事必须现在行动，使空间和时间先于解释可见。
- 缺关键过程：将承担职责的概述句还原为尝试、阻力和再选择，不扩写无关过场。
- 缺离场变化：确认信息、关系、资源、风险或决定至少一项改变，否则合并或删除场景。

## repair
只补写支撑转折所需的最小场景：保留既有结果与人物合同，让人物尝试、受阻、再选择，并把离场条件接回后文。删除重复结论，但不得为了“更有画面”扩写不改变任何条件的动作。

**保护项**：保护既有事件结果、人物选择归属、空间限制和后文入口，不能用新巧合替换原因果。

## facets
战斗场景用空间、资源和动作反馈组织因果，都市职业场景用权限与利益交涉，言情场景用关系目标和边界变化，日常轻小说场景可由尴尬、误读或默契改变关系。快节奏允许压缩过渡，慢节奏允许停留感受，但关键选择和状态变化都不能被概述替代。

## examples
1. 正例：谈判失败使队伍失去补给并被迫改道；反例：“争论许久后决定出发”，无可观察交锋。
2. 正例：搜查中误碰机关暴露人物习惯并关闭退路；反例：旁白概述“他们发现了机关”。
3. 正例：餐桌闲谈让一人拒绝同盟并改变座次；反例：整场对话交换背景，却无人改变行动。

## false_positives
移动、重复劳动和无关键选择的时间段允许概述；不要把所有叙述压缩都误判为缺场景。

## calibration
边界例：蒙太奇可以压缩多个结果相似的尝试，但关键失败与策略转变需落成场景；内心场景也要有刺激、解释和决定。场景离场不一定爆发危机，只要后续条件实际改变即可。
