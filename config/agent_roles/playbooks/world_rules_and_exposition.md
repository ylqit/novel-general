# 世界规则与信息投放

## core
规则通过使用条件、限制、代价、例外和失败后果建立。新名词出现时先给读者足够理解当前选择的信息，剩余背景按后续需要展开。不要连续罗列历史、势力、等级和术语，也不要让角色向本来就知道的人讲课。

## creation
玄幻与游戏能力必须能回答能做什么、不能做什么、消耗什么、如何被反制；都市与历史背景必须尊重时间、金钱、距离、职业流程和社会关系。信息投放要服务当前冲突，同时记录谁知道、谁误解、谁仍不知道。

## review
按条件、能力、限制、代价、反制和失败后果逐项核对，并区分“世界事实”“角色理解”和“有意谎言”。临时例外直接改变核心胜负且无前置证据时属于严重冲突；只缺当前场景理解所需的一小步信息时是局部说明问题。信息接收者本来就知道时，必须有冲突目的才允许解释。

**诊断分支**
- 规则未被证明：让人物使用、误用或承受限制，使规则通过结果而非旁白成立。
- 信息投放过量：只保留当前选择所需的规则、风险和例外，其余进入按需背景。
- 能力边界漂移：回查触发条件、资源、冷却和失败方式，修复最早的无代价越界。

## repair
先保留已批准规则与事件结果，把缺失信息放进一次使用、失败、质疑或反制；只补读者理解当前选择所需的最小信息。若结果只有新增例外才能成立，应交回改纲或 need-human，不由修章偷偷造规则。

**保护项**：保护已批准规则、例外、能力代价和人物已知范围，不能临时发明新限制或新豁免。

## facets
玄幻、仙侠和游戏异界突出能力条件与代价，都市和历史突出制度、金钱、距离与信息速度，科幻突出技术失效与社会后果，同人还要服从来源 canon 与声明分歧。熟悉题材术语可压缩，但本书独有规则必须由可观察后果定义。

## examples
1. 正例：能力救人后让使用者失去一次关键行动；反例：危急时临时宣布能力没有限制。
2. 正例：城市职业流程通过一次被退回的申请显现；反例：角色向同事完整讲解双方都熟知的制度。
3. 正例：武学反制先在训练失败中出现，实战兑现；反例：对手快获胜时才新增克制招式。

## false_positives
题材常识可以压缩；只有当前选择依赖且读者无法理解的信息才必须展开。

## calibration
边界例：第一章可以直接使用读者熟悉的“灵气”等术语，但本书独有边界必须通过后果说明；角色误解规则不等于设定矛盾，需要区分人物认知与世界事实。例外必须有来源、代价与可复用条件。
