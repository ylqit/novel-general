# 群像与视角

## core
每个活跃人物拥有独立目标、资源、盲点和决策权。群像章节不能只是主角逐个访问配角；至少有一个非主角选择改变局势。多视角切换必须带来新的信息权限、价值判断或行动能力，不能重复上一视角已经完整呈现的内容。

## creation
单场景维持清晰感知中心，避免无提示进入他人内心。不同视角应在注意对象、语言密度、风险判断和关系偏见上可辨认。长期分配按故事职责和因果需要，不用机械平均章数。

## review
检查每个活跃人物的目标、资源、决策权和因果贡献，再核对每次视角切换是否带来新权限或价值判断。无提示进入他人内心且影响读者对事实的判断时是 POV 失控；全知叙述或明确分场不应误报。角色暂时缺席不等于群像失败，需看滚动窗口职责。

**诊断分支**
- 配角无能动性：把一个真实资源、判断或决定交给有独立目标的成员，并让结果反作用主线。
- 视角切换无增量：删除重复复述，保留只有该视角能提供的误判、权限或行动能力。
- POV 越界：区分全知叙述、明确分场和无提示读心，仅修复会改变事实判断的越界。

## repair
保留主线锚点，把一个关键局势变化交给确有目标和资源的非主角人物；视角切换只保留新增信息、偏见或行动能力。删除重复复述时不得删除只有该视角能提供的误判、情绪代价或秘密。

**保护项**：保护主线锚点、各视角认知边界和非主角独有贡献，不以平均篇幅代替群像质量。

## facets
战争与权谋群像按资源和命令链分配视角，冒险团队按专长与风险分配能动性，言情多视角强调信息差而非重复感受，轻小说群像依赖可辨反应和社交位置。单主角模式激活时，非主角可有能动性但不能长期夺走主因果锚点。

## examples
1. 正例：配角私自谈判，缩小主角下一章的选择；反例：全员只等待主角分配任务。
2. 正例：切到医师视角揭示伤情与伦理代价；反例：换视角复述主角刚完成的战斗。
3. 正例：同一撤退命令在队长眼中是责任、在新兵眼中是抛弃；反例：不同 POV 注意对象和判断完全相同。

## false_positives
群像不要求机械平均篇幅；因果中心与当前卷职责可以让角色暂时缺席。

## calibration
边界例：单主角章节可以服务群像，只要非主角在其他节点保有决策权；短暂全知过渡若不进入多人内心可视为叙述连接。判断 POV 失控时看信息权限是否无提示越界，而非只看人称。
