# 同人还原与原创贡献

## core
先确定 canon 截止点、连续性模式、已声明分歧和角色当前关系阶段。原作人物必须保留自身目标、判断和拒绝能力，不能集体降智或只为原创主角提供奖励。与原作不同不自动等于 OOC，但变化必须能追溯到分歧、经历和后续代价。

## creation
允许使用专名、关系、规则和必要短语，不连续复现原作段落。原创贡献应形成新的冲突、选择和后果，而不是把原作事件逐章改写。联动作品必须维护独立命名空间、规则冲突和力量换算原则。

## review
先冻结来源命名空间、canon 截止点和声明分歧，再核对人物价值排序、关系阶段、能力规则、时间线与分歧后果。直接冲突或无依据能力越界可升级；语言风格差异通常需结合选择模式判断。与原作不同只有在缺少分歧因果时才构成 OOC。

**诊断分支**
- Canon 事实冲突：先核对来源、截止点和连续性模式，再判断是否已有声明分歧。
- OOC 缺因果：补变化的触发、抵抗和代价，不把角色强行改回原作静态快照。
- 原创主角吞噬原作：恢复原角色目标、拒绝权和独立行动，必要时重构让路冲突。

## repair
冻结本书已批准分歧和原创事件，为变化补足触发、抵抗与代价，同时恢复原作人物的目标、拒绝能力和关系历史。若剧情结果只能靠原角色集体降智成立，应改造冲突而非润色台词；不得复制原文恢复所谓还原感。

**保护项**：保护批准分歧、原创事件、原作价值排序和关系历史，不通过连续复制原文恢复所谓还原感。

## facets
续写重点核对 canon 截止点后的未决问题，前传重点防止未来知识泄漏，AU 重点建立规则替换，canon-divergent 重点追踪蝴蝶效应，crossover 重点维护命名空间和力量换算。恋爱或群像分面不能让原作角色失去自身目标来服务原创主角。

## examples
1. 正例：获救角色因政治债务改变立场并付出关系代价；反例：获救后无过渡地成为原创主角追随者。
2. 正例：AU 改变成长环境，仍保留角色的价值排序和拒绝方式；反例：只保留姓名与外貌，动机完全任意。
3. 正例：联动中两套能力按明确限制互相作用；反例：为让原创能力取胜而临时取消原作反制规则。

## false_positives
AU 和 canon-divergent 的差异不是天然 OOC；先检查声明分歧及蝴蝶效应。

## calibration
边界例：喜剧场景允许角色短暂夸张，但不能取消其核心判断；角色遭遇新创伤后声音变化可以成立，需有过程与代价。专名和招式相似不等于复制原文，连续表达复现另行审查。
