# 心理与情绪证据

## core
心理活动只保留能改变理解、选择、关系或压力的内容。不要在动作之后用内心独白重复同一事实，也不要用“他很愤怒、她十分震惊”替代身体反应、注意力变化和行为失控。人物可以自欺、误判和回避，但正文要让读者看见这种偏差如何影响下一步行动。

## creation
情绪推进需要刺激、即时反应、压抑或表达、选择及余波。重大创伤、失忆、身份错位和关系破裂不能只用一句设定交代；应在感知缺口、错误习惯、回避对象和现实应对中持续出现。

## review
沿刺激、身体反应、主观解释、压抑或表达、选择、余波追踪情绪链。重大动机依赖某种情绪却没有刺激和行为后果时是因果缺口；局部情绪命名只要没有重复动作含义，不必机械删除。心理若只复述刚写过的动作，按功能重复处理。

**诊断分支**
- 情绪无刺激：补触发或删去标签，不能让情绪凭作者需要出现。
- 心理复述动作：保留能改变解释或选择的部分，删除对刚发生事实的同义总结。
- 重大状态无持续痕迹：让失忆、创伤或身份错位在感知、习惯失效、回避和应对中回响。

## repair
保留人物已经做出的选择，把抽象情绪落到注意力偏移、身体控制、错误解释和下一步行为；让内心段在决定前改变阈值，或在决定后形成真实余波。删除动作后的同义总结，但保留自欺、迟滞和不可靠判断。

**保护项**：保护 POV 认知边界、人物自欺和合理延迟反应，不能把所有情绪外显成统一动作。

## facets
穿越与失忆要把身份断裂写进习惯失效和应对措施，言情把情绪写进边界与误读，热血在爆发前积累行动证据，黑暗题材保留麻木与延迟反应的合理性。克制型、武侠型人物可以少独白，但其注意对象和决定阈值仍须可见。

## examples
1. 正例：失忆者避开旧称呼，并因叫错名字改变选择；反例：只说“失忆令他痛苦”，后续毫无影响。
2. 正例：愤怒让角色先注意侮辱而漏掉出口；反例：动作后补一句“他非常愤怒”。
3. 正例：角色在道歉前反复整理杯沿，最终换成谈条件；反例：三段内心独白重复“我该不该相信她”。

## false_positives
克制人物可以少写内心，但必须能从注意、动作和选择看见情绪影响。

## calibration
边界例：高度自省的 POV 可以有长心理段，但每一段应推进解释或选择；创伤反应可以不持续外显，却要在触发场景留下感知或决策痕迹。身体反应也不能变成固定动作标签。
